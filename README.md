# IPTV Player для Windows 11 x64

**Языки / Languages:** [Русский](README.md) · [English](README.en.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [中文](README.zh.md)

Лёгкий 64-битный IPTV-плеер для Windows 11 на Rust. Минимальное потребление памяти и минимум взаимодействия с системой. Разработчик: **MSChina888**.

## Возможности
- Списки каналов M3U/M3U8 (по ссылке или локальный файл, выбор через «Обзор…»), порядок и группы берутся из списка.
- Телепрограмма XMLTV (.xml, .xml.gz), сопоставление по `tvg-id`, затем по `tvg-name`; логотипы из `tvg-logo` и EPG.
- UDP-мультикаст (`udp://@…`), UDP→HTTP прокси, выбор сетевого интерфейса.
- Избранное, сворачиваемые группы, скрытие каналов, текущая передача в строке канала и поверх видео (OSD).
- Полный экран, поверх всех окон, переход между мониторами, значок в трее, автозапуск, автообновление списков.
- Яркость/контраст/насыщенность, деинтерлейс, соотношение сторон, выбор аудиоустройства и языка дорожки, аппаратное ускорение GPU.
- Темы: светлая, тёмная, как в Windows. Настраиваемые горячие клавиши.
- Языки интерфейса: русский, английский, немецкий, испанский, французский, итальянский, китайский.

Без записи, планировщика и скриншотов — только просмотр.

## Установка
Скачайте `IPTVPlayer-Setup-<версия>.exe` в разделе [Releases](https://github.com/ssergo71/Apps/releases) и запустите. Настройки хранятся в `%APPDATA%\IPTVPlayer`.

## Сборка из исходников
Rust (MSVC), `cargo build --release` в папке `Src`, рядом с `iptvplayer.exe` нужен `libmpv-2.dll` (LGPL-сборка mpv). Установщик: Inno Setup, `Installer\installer.iss`.

## Технологии
Интерфейс — [Slint](https://slint.dev), воспроизведение — libmpv (LGPL).
